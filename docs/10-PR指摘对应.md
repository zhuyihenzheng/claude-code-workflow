## 如何让 Claude 复审

修复推送到同一 PR 后，逐条回复原指摘，并在 Conversation 留下修复 SHA、验证结果与复审范围；保留原线程等待 reviewer 确认。复审指令见[团队协作与 CI](06-团队协作与ci.md#5-修复后交给-claude-复审)。本仓库未启用根目录的 Claude workflow，评论本身不代表 Claude 已开始复审。
