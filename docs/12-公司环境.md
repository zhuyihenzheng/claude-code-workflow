# 12 · 公司环境

`company` 分支是在公司网络和客户项目里使用的版本。它与公开版用同一套规则、脚本和测试，只是把默认值改到“先获批准再打开”的一侧。

给信息安全部门的说明是日文的独立文档：[セキュリティレビュー資料](security-review.ja.md)。

## 1. 与公开版的差异

| 项目 | 公开版 | 公司版 | 原因 |
|---|---|---|---|
| 默认 MCP | Context7 + Playwright | 只有 Playwright | Context7 是远程服务，查询内容会发到服务方 |
| Context7 / GitHub MCP / DBHub | Context7 默认启用 | 全部在 [可选配置](../templates/mcp.optional.json) | 远程服务与数据库连接都需要先获批准 |
| 第三方插件、mod | 提供安装清单与团队推荐配置 | 不推荐、不分发；只用内置 mod | mod 在进程内运行，能读密钥和全部会话，不受沙箱约束 |
| bypassPermissions 模式 | 未限制 | 禁用 | 跳过权限确认的模式不适合客户项目 |
| claude.ai 连接器（Gmail、Drive 等） | 跟随账号 | 关闭 | 避免个人账号的连接器进入公司项目的会话 |
| Artifact 发布 | 跟随账号 | 关闭 | 发布即把内容传到 claude.ai |
| GitHub workflows | 可选 | 可选（不变） | 需要仓库写权限与密钥 |
| 管理员配置 | 无 | [managed settings 示例](../templates/managed-settings.example.json) | 项目里的设置开发者能改，强制项要由管理员下发 |

两版共用项目规则、评审流程、guard、Excel 处理和页面验证脚本。安装器会合并已有配置。已在目标项目中配置过的远程 MCP 会保留，导入后应核对两个客户端实际加载的服务器。

## 2. 导入前要先确认的三件事

这三件事不在仓库的控制范围内，但比仓库里的任何配置都重要：

1. **AI 服务的使用许可**：Claude Code 和 Copilot 会把代码、提示词、命令输出发到公司外。确认公司的合同与接入方式（直连、Bedrock、Vertex、公司网关），客户项目还要确认客户是否同意。
2. **网络与软件来源**：Playwright MCP 来自 npm，Excel 转换工具来自 PyPI，Chromium 来自 Playwright 的下载服务器。有内部镜像就用镜像。需要放行的地址见安全说明第 7 节。
3. **由谁下发强制策略**：把 [managed settings 示例](../templates/managed-settings.example.json) 交给管理 Claude Code 的部门，按公司的要求改值后下发。示例里的域名、保留天数都只是起点；MCP 白名单按完整启动命令放行 Playwright，升级版本时要同步改。

## 3. 导入步骤

```bash
git clone -b company https://github.com/zhuyihenzheng/claude-code-workflow.git
python3 scripts/install.py project /path/to/your-project --diff    # 预演
python3 scripts/install.py project /path/to/your-project --apply
```

然后：

1. 填写 `AGENTS.md` 的“本システム固有情報”。
2. 按项目真实的凭据位置补充 `.claude/settings.json` 的 deny 规则；模板里的 `*secret*`、`*credentials*` 只是按文件名猜。
3. 不做页面验证的项目，删掉 `.mcp.json` 里的 Playwright。
4. 不用 Excel 设计书的项目，删掉 `scripts/xlsx2ai.py` 和对应的 deny 规则。
5. 需要 Context7、DBHub 或 GitHub MCP 时，获批准后从可选配置里逐个合并。
6. 运行 `python3 scripts/install.py doctor /path/to/your-project`，把 `fail` 清零。

已有 `.claude/settings.json` 的项目，安装脚本只补缺失的规则和开关；已有的值与模板不同时保留已有值，并在输出里提示。

## 4. 这些配置挡不住什么

- 项目设置里没有 deny `curl`：验证流程要用它等本地服务就绪，而 allow 规则无法在 deny 里开例外；况且权限规则只匹配命令文本，换成 `python -c` 一样能发请求。对外通信的限制交给管理员下发的沙箱网络白名单。
- Read 的 deny 管不住任意脚本读文件。
- “不把客户数据交给 AI”是写给模型和人的约定，没有技术强制。
- 会话记录保存在 `~/.claude/projects/`，里面有代码和命令输出。保留期限由 `cleanupPeriodDays` 控制，设备本身的加密和外带限制要另行落实。

## 5. 维护方式

本仓库后续修改以 `company` 为工作分支。需要同步公开版时，在 `company` 上合并并验证第 1 节列出的公司版配置。本分支的测试会检查：默认 MCP 里没有远程服务、没有任何文件要求启用第三方插件或市场、公司版的开关都在。
