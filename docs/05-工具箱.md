# 05 · 工具箱：MCP / Skills / 插件 / Mods

按需要安装，以当前项目的验证结果选择工具。Star 数不代表正确性或安全性；工具数量也不能直接换算成固定的 token 账单。工具发现、延迟加载、缓存、版本与任务都会影响开销，用 `/context` 和实际用量测量。

## 1. MCP：默认两项，可选两项

| 工具 | 用途 | 本模板策略 | 一手来源 |
|---|---|---|---|
| Context7 | 查库文档与版本 | 默认公共 HTTP 接入；查询时仍核对版本覆盖，不保证每个版本都有资料 | https://github.com/upstash/context7 |
| Playwright MCP | 真实浏览器交互、截图和诊断 | 默认隔离浏览器；本地 npm 包固定直接版本 | https://github.com/microsoft/playwright-mcp |
| DBHub | 读取开发数据库结构与数据 | 可选；数据库层授予只读权限，不只依赖提示词 | https://github.com/bytebase/dbhub |
| GitHub MCP | 仓库、issue、PR 操作 | 可选；已有 gh CLI 时按实际需要选一种 | https://github.com/github/github-mcp-server |

配置见 [模板说明](../templates/README.md)。不要为启用不需要的 server 提供密钥。

Chrome DevTools MCP、Serena、Sentry 等按故障排查需求评估；没有同任务、同模型、同环境的比较，就不声称某工具“完全替代”另一工具。第三方安全评分不能替代代码审查、凭据收敛和运行隔离。

Playwright 的 `--isolated` 用于隔离浏览器状态，不是 OS 安全沙箱，也不意味着允许访问生产环境。DBHub 的 DSN 通过环境变量替换后作为子进程参数传入，可能出现在本机进程信息中；使用低权限临时凭据，勿记录完整命令行。

## 2. Skills 与方法论框架

- [anthropics/skills](https://github.com/anthropics/skills)：按任务选用。`webapp-testing` 当前主要指导原生 Python Playwright 脚本，**不要求 Playwright MCP，也不会自动把 MCP 配成测试回路**。
- [Superpowers](https://github.com/obra/superpowers)、[Matt Pocock skills](https://github.com/mattpocock/skills)、[Addy Osmani agent-skills](https://github.com/addyosmani/agent-skills)：先挑一条流程在小任务验证；不默认叠装多个完整框架。
- 项目技能用于稳定的重复任务，定义输入、产出、失败处理与验证步骤。示例见 [spring-endpoint](../templates/project/.claude/skills/spring-endpoint/SKILL.md)。
- 并非每个小改动都需要 spec、TDD、多个子代理和多轮 review。流程成本应与风险相称。

## 3. 插件

先在[官方市场](https://github.com/anthropics/claude-plugins-official)核对插件名、安装方式和运行依赖，再安装。Java 可优先试用 Java LSP 集成；JDK 与语言服务器要求以对应插件 README 为准。代码评审、提交辅助、权限检查等按需添加。

`code-review` 插件、Action 自动评审与托管 Code Review 产品是不同入口，不应混称“安装后就有的内置命令”。

## 4. 用量与并行工具

[claude-hud](https://github.com/jarrodwatts/claude-hud) 用于状态可视化，[ccusage](https://github.com/ryoppippi/ccusage) 可辅助统计。统计口径与真实账单可能不同，决策以账号/组织账单和实际交付质量为准。

并行开发先试独立 worktree，各自端口、配置、数据库与测试资源也需要隔离。工具多并不自动提升吞吐。

## 5. Mods

Mods 属于进程内扩展，应按运行任意本机代码的风险审查其源码、依赖、更新渠道与凭据访问。是否有组织下发限制、内置 mod 或某个配置键，以安装版本的官方文档为准；不要凭未经复核的发布日期或第三方目录判断安全性。

本仓库不默认安装任何 mod。评估标准：能解决现有痛点、可停用、可复现对比、来源与维护情况可核实。参见[官方 Mods 文档](https://code.claude.com/docs/en/plugins/mods/overview)。
