# JSP 編集ルール（JSP ファイルの編集時のみ読み込む）

- **scriptlet の新規追加は禁止**（`<% ... %>` や JSP 式 `<%= %>` に業務ロジックを記述しない）。新しいロジックはすべて Controller / Service に配置し、JSP は準備済みの model を描画するだけとする。
- 式には EL（`${...}`）+ JSTL タグ（`c:forEach`、`c:if`、`fmt:` など）を使用する。ユーザーが操作できるデータの出力は必ずエスケープする（`c:out` または `fn:escapeXml`）。これらは HTML テキスト／引用符で囲まれた通常の属性にのみ適用できる。URL はプロトコルとエンコーディングを検証し、JS/CSS のコンテキストには EL を直接埋め込まない。変更箇所ごとに適切な処理を確認する。
- JSP 内でデータベースを検索したり、EL/JSTL で表現できる範囲を超えた業務判断を行ったりしない。集計・整形が必要なデータは Controller 側で準備する。
- **必要最小限の修正**：タスクに関係する箇所のみを変更する。画面全体の並べ替えやタグの記法の一括変更をついでに行わない。既存 JSP はテストでカバーされておらず、広範な変更は影響範囲とリスクを把握しきれない。
- 変更後は必ずブラウザーで検証する。サービス起動 → 画面を開く → 描画結果をアサーションで確認し、スクリーンショットを保存する。JSP はコンパイル時のチェックだけでは不十分であり、構文や EL のエラーは実行時に初めて判明する。
- JSP を新規追加するかどうかは、プロジェクトの既存アーキテクチャに従って判断する。このテンプレートを理由に、独断でテンプレートエンジンを移行しない。
