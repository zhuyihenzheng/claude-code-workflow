# JSP 编辑规则（只在编辑 JSP 文件时加载）

- **禁止新写 scriptlet**（`<% ... %>`、表达式脚本 `<%= %>` 里写业务逻辑）：新逻辑一律放 Controller / Service，JSP 只根据已准备好的 model 渲染。
- 表达式用 EL（`${...}`）+ JSTL 标签（`c:forEach`、`c:if`、`fmt:` 等）；输出用户可控数据必须转义（`c:out` 或 `fn:escapeXml`），这些仅适用于 HTML 文本/带引号的普通属性；URL 要校验协议与编码，JS/CSS 上下文不要直接插入 EL，改到哪查到哪。
- JSP 里不查库、不做超过 EL/JSTL 能表达的业务判断；需要的聚合/格式化数据回 Controller 准备。
- **手术式修改**：只动任务相关的部分，不顺手重排整页、不批量改标签风格——老 JSP 没有测试覆盖，大面积改动风险不可控。
- 改动后必须走浏览器验证：起服务 → 打开页面 → 截图/断言渲染结果。JSP 没有编译期保护，语法与 EL 错误只有运行才暴露。
- 是否新增 JSP 由项目现有架构决定；不要因为本模板擅自迁移模板引擎。
